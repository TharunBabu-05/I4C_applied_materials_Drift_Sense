## 2. Dataset Generator Improvements (v2)

### 2.1 Major Architectural Changes

#### A. DRAM Structure Model Upgrade
**Previous:** Simple bright lines on dark background  
**Current:** Capacitor-body model with realistic DRAM SEM appearance

**Key Improvements:**
- **Dark square capacitor bodies** (storage node dielectric, low SE yield)
- **Bright metal interconnect walls** (tungsten/aluminum grid, high SE yield)
- **Rounded cell corners** from lithography resolution limits
- **Realistic material contrast** matching actual SEM imagery

#### B. Advanced Process Variation
**New Features Implemented:**
1. **Line Edge Roughness (LER)** - Correlated 1D fractal profile (1-3 px RMS)
2. **Critical Dimension (CD) Variation** - Global gradient ±5% across field
3. **Hierarchical Block Banding** - Subtle brightness bands every ~2000px
4. **Pitch Jitter** - Enhanced to 0.8px RMS for process variation

#### C. Manufacturing Defects
**New Defect Types:**
- **Missing contacts** - Randomly removed contact/via structures
- **Particle contamination** - Circular/elliptical particles (3-9px radius)
- **Poisson-distributed defect density** (0.0-2.0 defects per image)

#### D. Enhanced SEM Physics
**Additional Noise Models:**
- **Beam-current drift** - Sinusoidal scan-line modulation
- **Improved edge brightening** - Better secondary electron contrast
- **Enhanced vignetting** - cos^4 radial falloff
- **Advanced blur modeling** - Separate PSF for reference vs search

### 2.2 Parameter Updates

| Parameter | Previous Range | Current Range | Improvement |
|-----------|---------------|---------------|-------------|
| Poisson noise (ref) | 80.0-100.0 | 15.0-25.0 | More realistic shot noise |
| Poisson noise (search) | 40.0-60.0 | 6.0-12.0 | Higher search image noise |
| Edge brightening (ref) | 0.08-0.18 | 0.10-0.22 | Enhanced edge contrast |
| Cell pitch | 40-70px | 42-65px | More realistic DRAM dimensions |
| Line width fraction | 0.40-0.50 | 0.55-0.75 | Capacitor-body model |

### 2.3 Generation Performance
- **Previous:** ~3 seconds per pair
- **Current:** ~10-15 seconds per pair
- **Reason:** More complex LER generation, defect injection, advanced noise modeling

## 3. Inference Algorithm Enhancements (v2)

### 3.1 Algorithm Architecture Change
**Previous:** Single-scale NCC with phase correlation  
**Current:** 3-Level Multi-Scale NCC Pyramid

#### Pyramid Structure:
1. **Level 0 (Coarse):** Reference 1000→50px, Search 1000→500px (20x factor)
2. **Level 1 (Medium):** Reference 1000→100px, Search 1000→1000px (10x factor)  
3. **Level 2 (Fine):** Reference 1000→200px, Search 1000→500px (5x factor)

### 3.2 Algorithm Improvements
**Enhanced Features:**
- **Coarse-to-fine matching** - Reduces periodic ambiguity at multiple scales
- **Score fusion** - Combines results from different pyramid levels
- **Better disambiguation** - Center-bias for tied peaks with threshold tuning
- **Sub-cell refinement** - Higher precision localization

### 3.3 Performance Impact
- **Previous:** ~0.6 seconds per pair
- **Current:** ~0.25 seconds per pair
- **Improvement:** 2.4x faster due to optimized pyramid approach
